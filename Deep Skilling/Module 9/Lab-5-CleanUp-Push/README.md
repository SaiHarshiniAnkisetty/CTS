# Git Hands-On Lab 5 – Clean Up and Push to Remote Git

## Objective

- Verify that the local repository is in a clean state.
- List all available branches.
- Pull the latest changes from the remote Git repository.
- Push pending changes to the remote repository.
- Verify that the changes are reflected in the remote GitHub repository.

---

## Software Used

- Git Bash
- GitHub
- Windows
- Notepad

---

## Commands Used

### Navigate to Repository

```bash
cd ~/OneDrive/Desktop/GitHOL
```

### Verify Repository Status

```bash
git status
```

### List All Branches

```bash
git branch -a
```

### Pull Latest Changes from Remote Repository

```bash
git pull origin main
```

### Push Local Changes to Remote Repository

```bash
git push origin main
```

---

## Output

- Verified that the working directory was clean.
- Displayed all local and remote branches.
- Pulled the latest changes from the remote repository.
- Successfully pushed local changes to GitHub.
- Verified that all changes were reflected in the remote repository.

---

## Conclusion

Successfully performed repository clean-up verification and synchronized the local repository with the remote GitHub repository using **Git Pull** and **Git Push** commands.
