# Student Course Portal

## Project Overview

Student Course Portal is a standalone Angular 18 web application developed as part of the Cognizant Digital Nurture Angular Hands-On program. The application demonstrates core Angular concepts including components, data binding, directives, forms, services, routing, route guards, HTTP communication, and NgRx state management.

---

## Technologies Used

- Angular 18
- TypeScript
- HTML5
- CSS3
- RxJS
- Angular Router
- Angular Forms
- Angular HttpClient
- NgRx Store
